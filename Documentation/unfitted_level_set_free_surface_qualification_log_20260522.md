## 2026-05-26 Capillary Convention, Scope, And Transport Recheck

This update records the follow-up review against established unfitted-FEM
solver behavior and one-phase free-surface literature. The current supported
method is still a one-fluid embedded free-surface path: Navier-Stokes volume
terms integrate over one active level-set side, the generated interface is an
explicit embedded boundary, and the passive side is used only for support
operations such as velocity extension, constraints, stabilization, and
diagnostics.

The literature/solver comparison used the following public anchors:

- NGSolve CutFEM/XFEM docs for side-specific `dCut` integration, level-set
  normals, jumps, averages, Nitsche interface terms, and high-order cut
  geometry:
  <https://ngsolve.org/ngsolve/docs/i-tutorials/unit-8.3-cutfem/cutfem.html>.
- GetFEM XFEM docs for `p(x)<0`, `p(x)>0`, and `p(x)=0` integration plus
  `Xfem_plus`/`Xfem_minus` discontinuity handling:
  <https://getfem.org/userdoc/xfem.html>.
- Saye 2015 for high-order quadrature over implicitly defined surfaces and
  volumes: <https://doi.org/10.1137/140966290>.
- Massing, Larson, Logg, and Rognes for stabilized Nitsche fictitious-domain
  Stokes with velocity and pressure ghost penalties:
  <https://arxiv.org/abs/1206.1933>.
- Johansson, Larson, and Logg for high-order CutFEM Stokes with Nitsche
  interface conditions and stabilization:
  <https://arxiv.org/abs/1505.00372>.
- Olsson and Kreiss for conservative level-set transport:
  <https://doi.org/10.1016/j.jcp.2005.04.007>.
- Gross and Reusken for finite-element surface-tension force discretization and
  Laplace-Beltrami curvature treatment:
  <https://doi.org/10.1137/060667530>.
- SPHERIC Test 02, Test 05, and Test 10 benchmark pages:
  <https://www.spheric-sph.org/tests/test-02>,
  <https://www.spheric-sph.org/tests/test-05>, and
  <https://www.spheric-sph.org/tests/test-10>.

Findings from the comparison:

- The one-fluid active-side integration model is consistent with the
  side-restricted integration mechanisms exposed by NGSolve and GetFEM, but it
  is not a two-phase CutFEM/XFEM formulation. It does not yet implement
  side-specific material laws, two-sided traces, jump/average operators,
  pressure enrichment, or Nitsche interface coupling for two fluids.
- High-order implicit generated geometry is compatible with Saye-style
  quadrature as an integration strategy, but the current tangent policy is
  refreshed-frozen/quasi-Newton. Full Newton claims would require differentiated
  points, weights, measures, normals, curvature, and topology handling.
- The level-set transport path is scalar advection/SUPG plus optional repair
  and global shift correction. It is not a conservative level-set method in the
  Olsson-Kreiss sense.
- The capillary path is now sign-consistent for supplied/projected curvature
  static pressure-jump checks, but it is not yet a production dynamic
  capillary-flow method in the Gross-Reusken/Laplace-Beltrami or
  pressure-enriched two-phase sense.

Implemented code/documentation updates:

- Unfitted supplied curvature is now treated as signed with the raw generated
  interface normal `grad(phi)/|grad(phi)|`. Navier-Stokes converts it to the
  active-side outward-normal convention before forming
  `(-p_ext + gamma*kappa)n`.
- The same convention is documented in
  `Code/Source/solver/FE/Docs/LevelSet.md` and
  `IncompressibleNavierStokesVMSModule.h`.
- Runtime registration logs now include generated interface geometry,
  geometry tangent policy, shape-tangent status, curvature policy, curvature
  tangent policy, pressure stabilization policy, and the disabled reason when a
  pressure stabilization path is intentionally omitted.
- The level-set advection velocity extension now gathers nearest-interface and
  nearest-active velocity samples across MPI ranks before populating the
  prescribed `LevelSetAdvectionVelocity` field. This fixes the dry-rank
  distributed path where a rank with no local active/wet support could leave the
  prescribed advection field unpopulated before level-set assembly.
- The validation runner's MPI promotion now keeps the level-set equation on
  distributed FSILS GMRES and promotes the fluid equation to the FSILS
  Navier-Stokes block-Schur (`NS`) path, so checked-in `NS_*` fluid controls are
  active under MPI instead of being ignored by monolithic GMRES.
- The remediation outline
  `Documentation/unfitted_level_set_free_surface_bc_remediation_outline_20260526.md`
  now records the current status, literature alignment, and remaining promotion
  gaps.
